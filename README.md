# Misbah Afzal — Professional Portfolio

A responsive, one-page portfolio website built from the information in Misbah Afzal's resume.

## Preview locally
Open `index.html` in a browser. The site uses plain HTML, CSS and JavaScript; no build tools are required.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a new **public** repository named `YOUR-USERNAME.github.io` (replace `YOUR-USERNAME` with your GitHub username).
2. Upload `index.html`, `style.css`, `script.js`, and this `README.md` to the repository's root.
3. Open **Settings → Pages**. Under Build and deployment, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.
5. After GitHub Pages finishes publishing, your site will be available at `https://YOUR-USERNAME.github.io/`.

## Before publishing
- Check the phone number and email address in `index.html`.
- Confirm that all job titles, dates, metrics and case-study wording are accurate and that you are comfortable publishing them publicly.
- Add a LinkedIn profile link if you want one; it was not included in the supplied resume, so no link has been invented.
- Consider whether you want your phone number publicly visible. You can remove the phone link from the Contact section if you prefer email-only contact.

## Files
- `index.html` — portfolio content and page structure
- `style.css` — responsive visual design
- `script.js` — mobile navigation and current year
